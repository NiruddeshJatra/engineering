# engineering

My self-study CS curriculum, kept as an Obsidian vault. Module 1 (how a computer works) is closed; Module 2 (how the Internet works) is in progress. Progress tracking lives in Notion; this repo holds the notes.

**Folders:** `00-home.md` is the dashboard. `01-modules/` has one hub per module, `02-sources/` one note per chapter or episode, `03-concepts/` the concept atoms (flat; the module is a property), `04-questions/` every question I asked a person or an AI, `05-syntheses/` my cold answers to module questions, `06-assignments/` exams and code. `99-meta/` holds templates, Bases views and the writing style guide; `media/` attachments; `_archive/` retired material.

**How I use it:** read a source and take notes → park questions as one-liners → ask an AI only at the end of a section → close the tab and write what I now understand in my own words → write concept atoms at the end of a unit.
