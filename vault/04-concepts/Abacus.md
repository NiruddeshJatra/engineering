## Definition
First machine built to store numbers.

## Details
Abacas works like this: imagine a machine with four rows made with rods of wood or anything similar. In each row, there are beads. Now, each row represents a base in the number system. If you need to represent the number 247:
	- Slide 7 beads from the 1st row
	- Slide 4 beads from the 2nd row
	- Slide 2 beads from the 3rd row

## Why it matters to me as a dev
Interesting how anything can be thought to represent numbers. For example, fingers also.
