## Definition
basic features that every programming languages has

## Details
- **Data types**: C has data types like int, float, double, long, char, string. Each has a defined memory capacity
- **Syntax**: C requires precise syntax, such as ending every statement with a semicolon
- **Libraries:** To avoid reinventing the wheel, we use header files (like `stdio.h` or `cs50.h`) to include code others have already written, such as the `printf` function
- **Conditionals**: if, else if, else
- **Loops**: for, while, do while
- **Functions**: receive arguments, executes codes and can return a value also
 
## Why it matters to me as a dev
This is what we do, we write code. Knowing the rules of the coding game is the basic thing to know
