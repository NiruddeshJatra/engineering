## Definition
Professional code is judged on three axes: **Correctness** (does it work?), **Design** (is it efficient and logical?), and **Style** (is it aesthetically consistent and readable?)

## Details
- **Engineering Quality:** Software should be **Correct** (works as intended) and **Well-Designed** (uses the least CPU, RAM, and human time).
- **The Corner Case:** Professional code must handle "else" scenarios, like what to do if a search result isn't found. Failing to handle these cases is why software "freezes" or reboots.
- **AI as a "Co-Pilot":** While AI helps solve the "human bottleneck" of limited time and team size, you remain the "pilot" or "conductor". Understanding fundamentals ensures you can direct the AI effectively and fix its mistakes.

## Why it matters to me as a dev
We shouldn't just try to make the code working, we should also focus on making it efficient, readable, clean so that computer can execute it fast and anyone reading the code can understand it easily

## In my words
When we write any [[Programs]], we should at least know the [[Programming Basics]] and try to make the code use less resource and computational power of [[CPU]], less memory of [[RAM]] and be readable.
