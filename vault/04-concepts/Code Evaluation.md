
#medium   

## Definition
Professional code is judged on three axes: **Correctness** (does it work?), **Design** (is it efficient and logical?), and **Style** (is it aesthetically consistent and readable?)
 
## Why it matters to me as a dev
We shouldn't just try to make the code working, we should also focus on making it efficient, readable, clean so that computer can execute it fast and anyone reading the code can understand it easily
