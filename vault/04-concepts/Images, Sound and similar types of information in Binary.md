
#medium 

## Definition
standard code for representing image and sound

## Details
- any color can be made by combination of red, green and blue. We can set 3 numbers for representing how much of RGB is present in the color and in this way, we can actually represent any color possible. For example, (0,0,0) represents Black and (255, 255, 255) represents White. So, 8+8+8=24 bit binary number can be used to represent any color of any pixel of the screen
- Similarly, sound can be represented by numbers of frequency, amplitude etc.

## Why it matters to me as a dev
Understanding how anything possible can be made of some combination of numbers and turning those numbers to binary to store and use it in computers in mind blowing.
