
#medium 

## Definition
standard code for representing letter and other language symbols

## Details
- ASCII standardized representation of English letters and some daily use purpose symbols as 8 bit binary.
- Unicode standardized representation of all language symbols possible, including emojis. This solved the problem created by separate countries using separate standard for representing their symbols and letters.

## Why it matters to me as a dev
Understanding how any letter can be converted to binary is fascinating
