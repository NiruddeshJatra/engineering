## Definition
triggers electrical signals at regular intervals to keep all components synchronized

## Details
- The component which keeps the [[CPU]] ticking, running fetch-decode-execute cycle at every tick
- The speed at which a CPU can carry out each step of the fetch-decode-execute cycle is called its Clock Speed.
- This speed is measured in Hertz - a unit of frequency. One Hertz means one cycle per second.
- Overclocking means speeding up the tempo of the CPU for doing any required CPU intensive operation
- Clock sets the rhythm at which every instruction will be instructed by a CPU.
