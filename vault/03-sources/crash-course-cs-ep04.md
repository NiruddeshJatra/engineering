## What this episode covers
- How numbers and letters can be represented with only two states - 0 and 1
- How in base-10 notation each place of a number represents a base of 10, and similarly base-2 holds base of 2
- How floating point numbers can be represented in binary
- Bits and Bytes
- ASCII and Unicode system
- How images, music are represented also in binary


## What I understood
Everything in computer can be stored as long sequence of 0s and 1s - numbers, floating point numbers, negative numbers, images, codes, instructions, music - everything. For numbers, 2-base conversion can be used just like decimal numbers. For letters and pixels, standard code like ASCII and Unicode can be used.
