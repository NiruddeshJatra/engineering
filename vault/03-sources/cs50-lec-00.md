## What this episode covers
- How computers talk with 0s and 1s
- Representing Numbers, letters, emojis, picture, sound with binary

## What I understood
 David Malan started by showing a python script where he imported openAI. Using it he showed how we can locally use AI models and chat with it, configure it to give system instructions also.

Then, he talked about how data can be represented using binary with examples of fingers. I forgot how he transitioned from previous section to this section. His lecture was so engaging but I forgot why it felt engaging in this part.

Then, he showed how letters, emojis, colors and audio/video can be represented as binary. He also talked about bits and bytes, ASCII and Unicode.

He then showed how to search a name efficiently using binary search approach and how this is significantly better than linear search. He talked about algorithms, design decisions here.

David defined Computer Science not just as coding, but as the study of information and problem solving. He used a "black box" model where **Input** (the problem) goes in, an **Algorithm** (the secret sauce) processes it, and **Output** (the solution) comes out. He explained that we "stand on the shoulders of others". For example, you don't need to know binary to use Python because Python "abstracts" or hides those low-level details so you can be more productive.

Lastly, he showed how to use Scratch, graphical programming language. Using it, he explained programming concepts like conditionals, loops, variables, functions etc.

## Interesting Things to Know
OpenAI has a python package which can be imported locally to use any AI model and chat and give prompts. To know more: [https://pypi.org/project/openai/](https://pypi.org/project/openai/)

Damn! We can represent binary numbers with our hands. Like 1 - toe finger, 2 is 2nd finger, 3 is last 2 fingers etc. In this way, we can get 2^5 = 32 combinations to represent 0-31.

ASCII of A is 01000001. ASCII of a is 01100001. So, just by changing a bit, computers can go from uppercase to lowercase.
