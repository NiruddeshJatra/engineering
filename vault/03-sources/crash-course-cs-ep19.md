## What this episode covers

- **Volatile vs. Non-Volatile:** Memory (RAM) is volatile, meaning data is lost the moment power is cut, while storage (like SSDs or HDDs) is non-volatile and retails your data persistently.
- **Sequential vs. Random Access:** Archival storage like magnetic tape is sequential, meaning the system must physically fast-forward or rewind to find specific data, causing massive latency. Modern memory and storage rely on random access, allowing the system to read any specific address at any time.
- **Mechanical Latency vs. Solid State:** Traditional HDDs use spinning magnetic platters and moving read/write heads, which introduces physical latency known as "seek time". SSDs use integrated circuits with zero moving parts, dropping access times to under 1/1000th of a second.
- **The Memory Hierarchy:** Because SSDs are still much slower than RAM, computers use a tiered architecture to balance cost and speed. A system will utilize a small amount of incredibly fast, expensive memory (RAM) backed by a massive amount of slower, cheaper storage (SSDs or HDDs).
